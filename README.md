# Tetris Clone

A simple browser-based Tetris clone built with HTML, CSS, and JavaScript.

## How to Play

- Arrange falling tetromino pieces to fill horizontal lines.
- Filled lines disappear and score points.
- Game ends if pieces reach the top of the well.

## Controls

- **Left Arrow**: Move piece left  
- **Right Arrow**: Move piece right  
- **Down Arrow**: Move piece down faster  
- **Z**: Rotate piece left  
- **X**: Rotate piece right  
- **P**: Pause / Unpause  
- **R**: Reset game  

## Setup

1. Clone or download the repository.
2. Open `index.html` in your web browser.
3. Start playing immediately—no installation required.

## File Structure

- `index.html` — main HTML file  
- `main.js` — entry point, sets up game  
- `shapes.js` — tetromino definitions  
- `controller.js` — game logic and input handling  
- `game.js` — Game and Well classes  
- `tools.js` — utility functions  
- `mystyle.css` — game styles
